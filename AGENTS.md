# AGENTS.md

> Guidance for coding agents working in this repository (zfrqbl-website).

## What this is

Static HTML site for [zfrqbl.com](https://zfrqbl.com) — long-form essays and short
"X Is Not Y" notes written by Zafar. Deployed via Cloudflare Pages from the `main`
branch. Every page is server-rendered static HTML: no build step, no framework,
no client-side rendering. Pico CSS + hand-written `style.css`.

## Repo layout

- `index.html`, `about.html`, `archive.html`, `404.html` — top-level pages.
- `essays/*.html` — long essays (full prose, code-heavy).
- `notes/*.html` — short technical opinion notes (the bulk of the site).
- `templates/essay-template.html`, `templates/note-template.html` — copy when creating
  a new page. Keep them in sync with the pages you edit.
- `public/images/` — inline diagrams (webp). `public/og/` — Open Graph share images.
- `vendor/` — vendored Pico + Prism (do not edit directly).
- `_headers` — Cloudflare Pages response headers incl. CSP and cache rules.
- `robots.txt` — crawler policy (search/retrieval agents allowed, training crawlers
  blocked — this is a deliberate owner decision, do not reverse it).
- `sitemap.xml`, `rss.xml`, `llms.txt` — generated/kept current on publish.

## Conventions & hard rules

1. **Voice:** technical-opinion "X Is Not Y" style. Direct, concrete, no marketing
   fluff, no filler. Read the prose-gate policy before writing anything.
2. **Prose gate:** every commit touching `notes/` or `essays/` is checked by
   `tools/prose_gate.py` (pre-commit hook + CI). Rewrite flagged spans rather than
   bypassing. Exemption comments are allowed only when quoting AI text on purpose.
3. **Meta tags:** every page needs a `<title>` ≤ 60 chars and a meta description
   in the 100–160 char range, ending in sentence punctuation. Keep
   `og:title`/`og:description` in sync with the `title`/`description`.
4. **Images:** always set explicit `width`/`height` (real pixel dimensions, no
   `0`), meaningful `alt`, and `fetchpriority="high"` on the LCP/hero image.
5. **Scripts:** load JS with `defer` (see the prism includes at the bottom of
   essay/note pages). No render-blocking scripts.
6. **Theme toggle:** accessible name must contain the visible label
   (`aria-label="Toggle theme 🌙 / ☀️"`) — matches WCAG label-in-name.
7. **Header changes:** after editing `_headers`, verify with curl (see the comments
   at the top of the file); a malformed rule is dropped silently.
8. **Sitemap:** `sitemap.xml` is regenerated by a GitHub Action on push — do not
   hand-edit it.

## Typical workflows

- **Fix a site-quality issue** (per squirrelscan audit): run `squirrel audit`
  locally, then edit the flagged pages and re-audit until clean.
- **Add a note/essay:** copy the matching template, fill in the head + body,
  add the entry to `index.html`, `rss.xml`, `llms.txt`, `archive.html`, and let the
  sitemap action regenerate `sitemap.xml`. Run `tools/prose_gate.py <file>` before
  committing.
