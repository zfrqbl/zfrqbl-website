Project

UNSLOP — Write like a person

Twenty-two rules for text that does not sound machine-made. One plain-text file. An agent can load it at session start. A person can read it in two minutes.

Most AI-generated writing fails the same way: it is grammatically perfect and rhythmically dead. It pads claims with adjectives, hedges with filler, inflates importance, and signs off like a press release. UNSLOP is a checklist for the opposite. Every rule has a say this, not that example, so it works as a gate before anything ships.

Before and after

1. Hype words

Before: "This API elegantly leverages robust infrastructure to unlock transformative outcomes."

After: "This API does the job."

2. Machine rhythm

Before: "The rollout was completed approximately three weeks behind schedule due to recurring failures in the staging environment, which necessitated multiple revisions of the migration process."

After: "We shipped on Friday. The rollout ran three weeks late because staging kept failing, and we rewrote the migration twice."

3. Vague attribution

Before: "Studies show that AI agents will transform every industry."

After: "A 2023 NHTSA study of 400 drivers found..."

The rules

  1. Write like you talk. If a sentence sounds stiff when read aloud, rewrite it.
  2. Say what you mean. Plain claims beat adjectives. "Faster" not "blazing-fast".
  3. No hype words: leverage, harness, delve, robust, seamless, game-changing, unlock, elevate, transformative.
  4. No em dashes. Use commas or periods.
  5. No AI filler openers: "In today's fast-paced world", "It is important to note", "Let's dive into".
  6. No formulaic closers: "This one is worth your time", "Thank me later", "In conclusion".
  7. Short sentences. One idea per sentence.
  8. Active voice. "We built X", not "X was built by us".
  9. Numbers over adjectives. "85% faster" not "much faster".
  10. If the same word is the right word, use it again. Do not cycle synonyms.
  11. No rule-of-three by default. Use two points or four when the content calls for it.
  12. Delete filler words: very, really, actually, just, basically, essentially.
  13. No chatbot artifacts: "As of my last update", "I hope this helps", "Great question!".
  14. State confidence plainly. "I checked" not "I believe it is safe to say".
  15. Read it out loud. If you would not say it, cut it.
  16. Vary sentence length. Same-length sentences read machine-made.
  17. Say what something IS, not what it isn't. Kill "Not just X, but Y" and "No X. No Y. Just Z."
  18. Do not inflate importance. Facts do not need a significance bow. Watch: stands as, testament, pivotal, reflects broader.
  19. Cut the dangling "-ing" analysis tail. Watch: underscoring, highlighting, fostering.
  20. Name the source or delete the claim. Never "studies show" or "experts believe".
  21. Kill metaphors you have seen in print. Watch: landscape, realm, tapestry, backbone, navigate.
  22. Prefer verbs over noun-ified actions. "We decided" not "we made the decision".

Install

Clone the repo, then one line per agent:

git clone https://github.com/zfrqbl/unslop

# Claude Code
curl -fsSL https://raw.githubusercontent.com/zfrqbl/unslop/main/UNSLOP.md -o UNSLOP.md
mkdir -p .claude/skills/unslop && cp UNSLOP.md .claude/skills/unslop/rules.txt

# Cursor
curl -fsSL https://raw.githubusercontent.com/zfrqbl/unslop/main/UNSLOP.md -o .cursor/rules/unslop.mdc

# Codex
curl -fsSL https://raw.githubusercontent.com/zfrqbl/unslop/main/UNSLOP.md -o AGENTS.md

# Hermes
mkdir -p ~/.hermes/skills/unslop && cp UNSLOP.md ~/.hermes/skills/unslop/rules.txt
