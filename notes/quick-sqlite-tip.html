Quick Tip: Enabling WAL Mode in SQLite Connections

If you are running multi-threaded workers reading and writing to local SQLite database files, execute PRAGMA journal_mode=WAL; immediately upon opening a connection.

PRAGMA journal_mode=WAL;
PRAGMA synchronous=NORMAL;

This prevents sqlite3.OperationalError: database is locked errors under concurrent query workloads.
